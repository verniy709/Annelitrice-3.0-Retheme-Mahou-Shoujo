# Annelitrice 3.0 Retheme Mahou Shoujo (RimWorld 1.7)

Load this add-on after Annelitrice 3.0. It gives the race a magical-girl parody theme, with Wish Fragments, Soul Gems, Magical Lollipops, a Moonlight Fountain, and new childhood stories. English text patches are in `1.7/Patches/`; Simplified Chinese translations are in `1.7/Languages/ChineseSimplified/DefInjected/`.

The patches also adapt the larva variants and butchery products. Adult Annelitrice yield 30 Magical Lollipops, larvae yield 10, and reclaiming a Wish Fragment yields 5. The text for the healing wand describes its current preventive effect: it blocks new infections for about five days but does not cure existing infections.

The artwork directory is `Textures/Anneli_Retheme_MahouShoujo/`. Some images are still reused from the Dark Souls retheme. Restart RimWorld after changing artwork. An in-game load test is still needed.
